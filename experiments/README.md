# experiments/

This directory holds illustrative ports of Aether language ideas into other
languages.  Each experiment is a deliberately small proof-of-concept — meant
to show what a specific Aether concept looks like in a mainstream setting, not
to be a production tool.  Every sub-directory contains its own README with an
honest statement of what works, what is a sketch, and what would be required
to make it real.

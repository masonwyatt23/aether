# Aether Playground

A browser-based playground for the [Aether programming language](https://github.com/masonwyatt/aether).
The parser, type checker, and tree-walking interpreter run entirely in your browser as a WebAssembly module — no server, no internet connection required after the initial page load.

## Build

From the `playground/` directory (or anywhere in the repo):

```bash
cd playground
./build.sh
```

The script:
1. Installs `wasm-pack` via `cargo install` if it isn't already present.
2. Runs `wasm-pack build --target web` on `crates/aether-wasm`, writing the JS/wasm bundle to `playground/pkg/`.

**Prerequisites:** Rust toolchain + `wasm32-unknown-unknown` target.

```bash
rustup target add wasm32-unknown-unknown
```

## Serve locally

Any static file server works. The playground uses ES modules, so it **cannot** be opened as a `file://` URL — you must serve it over HTTP.

```bash
python3 -m http.server 8080 -d playground
# then open http://localhost:8080
```

Or with Node:

```bash
npx serve playground
```

## Usage

| Button | Keyboard | Action |
|--------|----------|--------|
| **Run** | `Ctrl+Enter` / `Cmd+Enter` | Type-check then execute `main()`. Captured stdout appears in the output pane. |
| **Check** | — | Parse + type/effect/refinement verify. Diagnostics include line:col. |
| **Format** | — | Pretty-print the source. Toggle "verbose fmt" for the human-readable form. |
| **Introspect** | — | Render the module's public surface (equivalent to `introspect("current")`). |

The **Tab** key inserts two spaces instead of changing focus.

## Caveats

- **Network tools** (`http_get`, `llm_complete`, `mem_get`, `mem_set`) are replaced by deterministic stubs in the browser. `llm_complete` returns a hash-derived stub string; `mem_get`/`mem_set` are no-ops.
- **Import resolution** is disabled — each program must be self-contained (no `import` statements).
- **Wasm size** is unoptimised in debug builds. For a smaller bundle use `wasm-pack build --release`.

## Files

```
playground/
  index.html     — single-page app shell
  index.css      — dark-theme styles (no external deps)
  main.js        — wasm initialisation, button wiring, output rendering
  build.sh       — build script (chmod +x)
  pkg/           — generated by wasm-pack (git-ignored)
```

```
crates/aether-wasm/
  src/lib.rs          — wasm-bindgen exports + native Rust API
  tests/wasm_smoke.rs — native integration tests (run with `cargo test -p aether-wasm`)
```
